# 🎲 Dice Roller

A simple Python command-line Dice Roller that simulates rolling two dice. The user can choose to roll the dice or exit the game.

## 🚀 Features

- 🎲 Rolls two six-sided dice
- 🔄 Allows repeated rolls using a loop
- ✅ Enter `y` to roll the dice
- ❌ Enter `n` to exit the game
- ⚠️ Handles invalid choices

## 🛠️ Technologies Used

- Python
- `random` module

## 📌 How It Works

1. The program asks the user if they want to roll the dice.
2. Enter `y` to roll two dice.
3. Each die generates a random number between `1` and `6`.
4. The results of both dice are displayed.
5. Enter `n` to stop playing.
6. Any other input displays an `Invalid Choice!` message.
